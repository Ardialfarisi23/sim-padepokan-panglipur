# 🥋 SIM Padepokan Pencak Silat Laskar Panglipur
*Sistem Informasi Manajemen berbasis Laravel & React untuk efisiensi administrasi data.*

---

## 📌 Project Overview
Proyek ini dirancang untuk mendigitalisasi manajemen data pada organisasi Laskar Panglipur. Fokus utamanya adalah efisiensi administrasi data anggota menggunakan arsitektur modern.

## 🛠️ Tech Stack
- **Backend:** Laravel (PHP)
- **Frontend:** React.js & Tailwind CSS
- **Database:** MySQL
- **Design:** Figma (UI/UX)

## ✨ Key Features
- Dashboard Analytics data anggota.
- Manajemen CRUD data administrasi terpusat.
- Antarmuka responsif untuk berbagai perangkat.
